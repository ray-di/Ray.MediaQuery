# Claude AI Support for Ray.MediaQuery

This document contains information about utilizing Claude AI for the Ray.MediaQuery project.

## Project Overview

Ray.MediaQuery is a PHP library that provides unified handling of database queries and web queries. It allows annotation-based query definition and execution through dependency injection.

## Key Features

- **SqlQuery**: SQL query execution and mapping
- **WebApiQuery**: Web API query execution
- **Pager**: Pagination functionality
- **ParamConverter**: Parameter conversion
- **ParamInjector**: Parameter injection

## Project Structure
